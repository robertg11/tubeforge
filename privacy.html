Privacy Policy

TubeForge Upload · Last updated: 28 October 2026

TubeForge Upload is a private tool used only by its owner to publish the owner's own videos to the owner's own YouTube channels. This policy explains what data it touches and how.

YouTube API Services

TubeForge Upload uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data is accessed

When the owner signs in with Google, the tool receives permission for two scopes:

  • youtube.upload, to upload videos;
  • youtube.force-ssl, to set thumbnails and add captions on those videos.

The tool sends the owner's video files, thumbnails, captions, titles and descriptions to YouTube. It reads back only the ID and status of the uploaded video.

What is stored

The OAuth access token and refresh token are stored only on the owner's own computer, in a local configuration file. Nothing is stored on any server operated by the tool. No analytics, cookies or tracking are used.

Sharing

No data is sold, shared or transferred to anyone. Data goes only to Google/YouTube, as needed to publish the video.

Other people's data

The tool does not access, collect or store any data about viewers, commenters or any other YouTube users.

Revoking access

Access can be revoked at any time from Google Account permissions. Deleting the local configuration file removes the stored tokens.

Contact

Questions about this policy: use the support email shown on the Google sign-in screen of TubeForge Upload.
